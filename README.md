# 强制报告智能体演示系统

Node.js 20以上，无需安装依赖。工作目录运行 `npm start`，首页 http://localhost:3000 进入智能问答。

- 公众报告端：http://localhost:3000/report
- 接收工作台：http://localhost:3000/receiver
- 验证流程：报告端填入虚构案例并提交；公安端打开详情，填写复核依据并确认A标签；点击模拟超期；切换检察院查看监督摘要。
- 帮扶流程：公安确认B标签，填写脱敏摘要，选择部门分流；切换对应部门，保存帮扶记录或升级回公安。

报告、附件及访问操作日志保存在 `data/database.json`，重启后保留。浏览器保存报告回执查询凭证。处置时限为24小时，自公安接收时起；帮扶升级回公安时重新起算。AI建议不触发终审定性，人工确认A类后才触发监督。已立案、不予立案、分流帮扶、已归档视为完成阶段处置；A类不予立案仍推送监督。

默认监听0.0.0.0:3000，可通过内网穿透转发3000端口。接收端按要求免登录，切换部门仅演示权限范围，任何访问者都能选择公安角色。请仅填虚构数据，不用于真实案件。

公众端已包含智能问答、五条虚构情景实训、岗位普法学习、报告表单、个人记录和单位培训台账。问答、实训角色对话和复盘接真实AI；接收端保持规则研判与公安人工确认。

运行 `npm test` 执行流程测试。测试使用独立临时数据目录和本地模型协议测试服务，不写入演示数据库、不消耗真实AI额度。

UI 按 Wise 风格统一为浅绿背景、深绿文字与青柠主操作。公众端使用左侧导航；接收端保留部门导航、统计、筛选和详情弹窗。公众组件在 `public/portal.css`，通用与接收组件在 `public/style.css`。

## 公众端入口

- 智能问答：http://localhost:3000/ask
- 情景实训：http://localhost:3000/training
- 岗位普法：http://localhost:3000/learning
- 个人记录：http://localhost:3000/records
- 单位台账：http://localhost:3000/ledger

左侧可切换普通公众、虚构教师、医护或社区村居身份；实训面向义务主体，单位台账使用虚构单位，免登录切换不代表正式账号权限。

报告表单自动保存草稿，包含其他选项说明、联系信息和附件；按当前演示身份保存在本浏览器，文字使用 localStorage，附件使用 IndexedDB。刷新或离开后可从“我的记录 → 草稿 → 继续填写”恢复内容及滚动位置；“新建线索”保留已有草稿并开始另一条线索，成功提交仅清理对应草稿。清除浏览器数据或换浏览器后无法恢复这些本地草稿。

智能问答提供9个快捷问题，每组3个，默认每8秒自动轮换，以淡出、淡入动画切换，无手动轮换或暂停控件；鼠标悬停、键盘聚焦或输入时暂缓轮换，减少动态效果偏好下仍自动轮换但不播放过渡动画。输入框默认一行，随输入自动增高，最多160px后内部滚动；桌面聊天卡片与最近对话列表上下对齐，回答区域使用剩余空间。接收端在风险等级旁显示基于事件类型的报告情形标签，仍需人工核实。提交成功页面提醒报告者信息仅供内部核实与联系，不对外公开。

## 真实 AI 配置

服务端从 `FREE_API_KEY` 环境变量读取原有通道密钥；Windows 进程没有该变量时，依次读取本机 User、Machine 范围同名变量。密钥只留在服务端内存，不下发浏览器、不写入数据。修改后重启服务。

调用 `https://api.fuka.win/v1/chat/completions`，三个可选网关模型标识为：

- `[故人情]gemini-3.8-flash`，默认。
- `[故人情]gemini-2.5-pro`。
- `[故人情]gemini-3.1-pro-preview`。

`FREE_API_KEY_2`、`FREE_API_KEY_4` 对应 `https://jianzhile.vip/v1`；`FREE_API_KEY_3` 已改为 `https://api.fuka.win/v1`。每次启动分别查询 `/models`，只加入各密钥目录中的对话模型。同型号的渠道前缀和圆圈编号不单独显示，Thinking、Search 等功能区别保留；调用时后端使用对应密钥、地址和原始模型ID。某通道在开始输出前失败，可尝试同型号的其他授权通道；已经输出片段后不切换通道拼接答案。

新增型号在内部以 `jianzhile:` 或 `fuka:` 区分网关，已存在的型号保留原ID，页面只显示型号名称。图标与对话头像按厂商匹配 `public/assets/` 中的 SVG；所有 GPT 型号统一使用 OpenAI 图标。Claude 尚无用户提供的 SVG，暂使用 C 标记占位。目录为空或未配置的密钥不添加虚构选项。`AI_SECONDARY_BASE_URL` 可覆盖第2、第4通道地址，`AI_KEY_3_BASE_URL` 可覆盖第3通道地址；测试使用 `AI_CATALOG_ENABLED=0` 关闭真实目录发现。

网关返回 429 且提供 10 秒以内的 `Retry-After` 时，在总响应超时范围内最多等待重试两次；已经开始输出文字的请求不自动重试。

界面使用 Gemini 完整名称及图标菜单。问答、实训角色对话和复盘均使用真实 SSE 流式输出；片段到达后立即显示，完整回答生成成功后保存。调用失败显示错误，可切换模型后重试；不会用模拟回复替代。每条回复保存使用的模型。`AI_BASE_URL` 可覆盖网关地址，`AI_TIMEOUT_MS` 默认 60000。

刷新或离开页面时，已经接收的生成请求会在上述超时范围内继续完成并保存；重新打开同一会话可恢复查看生成进度。未完成的片段不写入历史对话，也不作为后续模型上下文。

尚未接入案例知识库。内置制度要点、官方来源链接和五条虚构实训案例集中在 `content.js`，后续可替换数据来源。

问答和复盘提示词集中在 `ai.js` 的 `qaSystem`、`feedbackSystem`。问答以案例、报告制度与保护实践为主题，按问题自由组织回答，制度摘要作为背景参考；不强制五项结构或每次重复免责声明。复盘可按需要展开，保留既定规则分数，不再限定500字。情景实训的角色提示词在 `portal-api.js`，继续根据案例背景扮演角色。

## 实训、记录与台账

实训覆盖疑似受侵害未成年人、情绪激动家长、不配合监护人。风险识别、问询沟通、报告判断、证据梳理、模拟上报各20分，80分达标；固定检查点计分，AI生成纠错。支持保存填写进度、刷新继续，完整对话、作答、模型、评分和反馈后端持久化。

实训“模拟上报”只保存训练作答，不向公安队列提交；真正提交线索须使用报告表单。

问答、实训、学习、报告和日志均保存在 `data/database.json`，重启保留；报告回执凭证存浏览器。可删除个人记录，学习和实训删除后单位台账同步更新。单位CSV含完成情况、总分和五项分数，不含对话全文、报告描述或附件。

24小时是本项目演示处置时限，不是内置法条规定的统一法定期限。帮扶部门接口不提供报告人信息、精确地址、原始案情或附件；检察端仅见监督摘要。

AI请求有每连接IP每10分钟30次、全局最多3个并发的演示限额。`PORT` 可改端口，`DATA_DIR` 可覆盖数据目录。只使用虚构数据。
